The problem

MCP servers publish tool descriptions that steer model behavior. After you install a server, that metadata can change — new URLs, new file paths, softened permissions, or instructions that were not there yesterday — without a release note you will notice.

Plumbline observes public tool metadata, hashes it into an append-only Merkle log, and classifies diffs with a deterministic taxonomy. Anyone can check that the log has not been rewritten using only the CLI and the published public key.

What this is not

Not an app store. Not a reputation score. Not a sandbox for running tools. It is a transparency log: signed tree heads, inclusion proofs, consistency proofs — verifiable by people who do not trust the operator.
