Plumbline

An append-only Merkle transparency log of publicly published MCP tool metadata. It records what a tool claimed to do at observation time, as a hash, so later changes are visible without trusting the operator.

What drift means here

Drift is a post-publication change in a tool’s canonical metadata — description, schemas, or annotations — relative to a prior observation of the same server and tool. This site does not publish findings while the study is running. The log itself is published so anyone can verify the tree independently.

Why a public log

A database you have to trust is not a transparency log. Signed tree heads, inclusion proofs, and consistency proofs let a third party check that history was not rewritten. That is the same idea as Certificate Transparency and Sigstore Rekor, applied to MCP tool metadata.

How to verify it yourself

You do not need to trust this site. Download the static bundle and check signatures with the CLI: 

plumb verify-log --bundle https://<this-host>/log/

Full instructions: /verify/. The Ed25519 public key is at /log/pubkey.txt.

Zero third-party requests

This site makes no analytics calls, loads no webfonts, and contacts no CDN. Assets and JSON are self-hosted. That matches the CLI’s zero-egress promise for local checks: nothing phones home.
