Verify the log without trusting us

You need only the plumb CLI, the published Ed25519 public key, and a copy of the static bundle (this site’s /log/ directory, or a mirror of it).

1. Obtain the public key

Fetch /log/pubkey.txt over HTTPS, or use the in-repo copy docs/log-public-key.ed25519. Compare them; they must match.

2. Verify the static bundle

plumb verify-log --bundle https://<this-host>/log/ \
  --pubkey-hex $(cat log/pubkey.txt)

Or against a local checkout of the published files:

plumb verify-log --bundle ./site/log \
  --pubkey ./site/log/pubkey.txt

What that checks

  • Every checkpoint in checkpoints.json has a valid Ed25519 signature under the published key.
  • Consistency proofs between consecutive checkpoints verify (RFC 6962).
  • Exit code 0 means OK; 1 means a signature or consistency failure (the failing checkpoint is named).

3. Optional: live HTTP API

If a conforming log HTTP API is available, the same CLI accepts --url and additionally re-hashes leaves and checks inclusion proofs. See docs/VERIFY.md.

Independent of this site

HTML and JavaScript on this origin are convenience only. Verification does not require loading this page, enabling JavaScript, or trusting our hosting. Anyone can re-host the /log/ JSON and point plumb verify-log --bundle at their mirror.
