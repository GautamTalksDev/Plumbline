# Support

## How to get help

- **Bugs and feature requests:** open a [GitHub issue](https://github.com/GautamTalksDev/Plumbline/issues).
- **Security vulnerabilities:** see [SECURITY.md](SECURITY.md). Do not file public issues for security reports.
- **Contribution questions:** see [CONTRIBUTING.md](CONTRIBUTING.md).

## What to include

When filing an issue, include:

- Plumbline version or commit SHA
- Go version and OS
- Steps to reproduce
- Expected vs actual behavior
- Relevant logs (redact secrets)

## Response expectations

This is an early-stage project. Maintainers will triage issues as capacity
allows. There is no formal SLA.
