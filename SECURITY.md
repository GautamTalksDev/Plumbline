# Security Policy

## Supported Versions

Security fixes are applied to the default branch only while the project is
pre-1.0.

## Reporting a Vulnerability

Do **not** open a public issue for security vulnerabilities.

Email the maintainer via the contact method listed in the GitHub repository
profile, or use GitHub's private vulnerability reporting if enabled for this
repository.

Please include:

- A description of the issue
- Steps to reproduce
- Affected versions or commit SHAs
- Any known mitigations

You should receive an acknowledgment within a few business days. We will
coordinate disclosure timing after a fix is available.
